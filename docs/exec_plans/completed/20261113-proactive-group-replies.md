# 主动群聊回复

状态：2026-11-14 已完成。主动回复正式开启，实际两条 QQ 发送回执为 sent；后文按时间保留实现、影子联调和上线过程。

## Goal and acceptance

在 `5880e68` / `0.9.19-kirito.3` 上增加默认关闭、按群启用的主动回复。只接原生决策模型：TypeSafe、OpenRouter Decisions、Vercel TypeSafe-compatible、自定义 System One 兼容端点；不增加聊天模型结构化输出适配器或新的运行时依赖。@ 和经校验的引用回复沿用原通道。

验收例子：未 @ 的多人消息只旁听；决策允许后，以成员权限把目标及相关原文交给原群会话；保留各自身份与引用，已提交消息不重复写入。决策拒绝/超时/错误无可见输出。主动回合只在完成后发送一次文字，静音、停止、新的显式请求、撤回、断线或过期会撤销待发内容；不会中间发送、调用 QQ 写工具或离线补发。冷却/限额、90 秒内最多两轮的相关跟聊、影子模式与关闭开关有效；群与私聊隔离。

## Approach

1. 阅读根说明、服务记录、插件 AGENTS 与现有入站/回合/出站/测试接口；查官方 provider 契约。
2. 增加决策 HTTP 适配器、旁听缓冲/上下文组装和调度；接入入站、回合与出站的已有边界，默认 off、启用后先 shadow。
3. 增加配置与文档；只记录凭据的环境变量名。每群共享原 dsh 回复会话，选中的旁听原文会进入历史，明确此边界。
4. 实现完成后统一补充行为测试，构建、类型检查、全量测试和打包验证。
5. 更新运维服务说明与本计划。未获本次明确推送/部署指令前不发布；真实 provider/QQ 验证需要受保护的 provider 凭据及 AgentSSH。
